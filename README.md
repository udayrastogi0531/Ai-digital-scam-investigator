## 🚨 The Problem

Digital scams are no longer limited to obvious spam messages.

Modern scams can involve:

- 🎣 Phishing links
- 🏦 Fake banking alerts
- 💼 Job and recruitment scams
- 💳 Payment requests
- 📦 Delivery scams
- 💰 Investment / crypto scams
- 👤 Impersonation
- 🔐 Account takeover attempts
- 🎁 Lottery / reward scams
- 🛠️ Fake technical-support messages
- 💕 Romance scams
- 🪪 Identity-theft attempts

A simple keyword matcher or an LLM asking:

> "Is this a scam?"

is not enough.

The **AI Digital Scam Investigator** treats scam detection as an **investigation problem** rather than a simple classification problem.
